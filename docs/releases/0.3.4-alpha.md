# Ruwa 0.3.4-alpha — Strokes and details

31.08.2026

This release adds brush dynamics driven by pen tilt and stroke speed, copying a
selection to a new layer, and radius controls for effects on the canvas.

- Brushes gain pen tilt and stroke speed curves, dynamics smoothing, drag reordering, a
  list view and adjustable preview sizes.
- Ctrl+J copies a raster selection to a new layer; Ctrl+Shift+J cuts it to a new layer.
  Copy Merged (Ctrl+Shift+C) copies the visible result inside the selection.
- Twirl, Pinch and Ripple have radius rings you can drag on the canvas. Canvas Resize
  snaps to canvas and layer edges.
- Brush blending uses the target layer correctly. Fill and Delete Content work across
  selected layers and groups. Floating panels return when a layout is restored.

Ruwa is still alpha software. Keep backups of your projects.
