# Ruwa 0.3.5-alpha — Continuous strokes, easier imports, and effects you can place

15.09.2026

This release connects and refines brush dabs into continuous strokes, adds a
visual drag-and-drop importer for Ruwa and Photoshop brush files, and puts
effect positions directly on the canvas.

- Connect Dabs, Refine Previous Dab and segmented transforms create continuous
  strokes through sharp turns. Wet brushes use the same refined joints and now
  respect brush textures.
- Drop `.rbf` or modern Photoshop `.abr` files onto Ruwa, preview their brushes,
  choose which to include, and import them as a new pack or into an existing one.
- Drag Gradient Overlay endpoints and the centres of Radial Blur, Twirl, Pinch
  and Ripple on the canvas, including into negative document coordinates.
- Brush settings save without blocking the interface. Smudge and low-alpha wet
  colour are more reliable, and closing a canvas no longer risks an undo-history
  crash.
- First-run setup follows the system language when available and lets the
  language be changed before the rest of the setup is read.
- The redesigned liquid-glass release-notes popup opens one version at a time
  from a compact navigator, animates between versions, and can copy the selected
  entry as plain text.

Ruwa is still alpha software. Keep backups of your projects.
